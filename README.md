# ✂️ Agendamento Barbearia

Sistema completo de agendamento online para barbearias, desenvolvido com Node.js, TypeScript e SQLite.

## 🚀 Tecnologias

- **Backend:** Node.js + Express + TypeScript
- **Banco de dados:** SQLite (better-sqlite3)
- **Autenticação:** JWT + bcrypt
- **Frontend:** HTML, CSS e JavaScript puro

## ✅ Funcionalidades

### Cliente

- Agendamento online sem cadastro
- Calendário visual para seleção de data
- Visualização de horários disponíveis em tempo real
- Seleção de barbeiro e serviço
- Contato via WhatsApp

### Barbeiro (Painel protegido)

- Login com JWT
- Agenda do dia com resumo de receita
- Relatório por período
- Concluir e cancelar agendamentos
- Seleção múltipla para exclusão
- Cadastro e remoção de barbeiros
- Contato direto com cliente via WhatsApp
